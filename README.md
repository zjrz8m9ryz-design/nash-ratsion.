# «Наш рацион» — заготовка для GitHub Pages и еженедельной проверки цен

## Что уже подготовлено
- `index.html` — сайт с меню и списком покупок.
- GitHub Actions workflow запускается по понедельникам и вручную.
- `scripts/update_prices.py` проверяет настроенный CSV-источник и сохраняет статус.
- `data/prices.json` хранит дату проверки и статус источника.

## Важно про реальные цены
GitHub может бесплатно запускать задачу по расписанию, но сам по себе он не даёт доступ к ценам магазинов. В этой заготовке автоматический источник цен **ещё не подключён**. Пока статус `not_connected`, цены в исходном HTML остаются ориентировочными; задача не будет подставлять выдуманные цифры.

Чтобы включить реальные обновления, нужен стабильный разрешённый источник (API или CSV) с ценами для Калининграда. Поддерживаемый CSV должен содержать колонки:
`product,store,price,checked_at`

После получения такого URL добавьте в GitHub репозитории секрет `PRICE_FEED_URL` (Settings → Secrets and variables → Actions). Тогда еженедельная задача сможет загрузить CSV. Если у магазина нет открытого API/экспорта, нужно отдельно подобрать законный и устойчивый источник; страницы каталогов могут быть динамическими, привязанными к адресу или карте лояльности.

## Как опубликовать сайт
1. Создайте аккаунт на GitHub, если его ещё нет: https://github.com/
2. Создайте новый **Public repository** (например, `nash-ratsion`). Для GitHub Pages бесплатный публичный репозиторий — самый простой путь.
3. Загрузите содержимое архива в корень репозитория. Важно загрузить именно содержимое папки, а не сам ZIP.
4. Откройте Settings → Pages.
5. В разделе Build and deployment выберите `Deploy from a branch`, ветку `main`, папку `/ (root)`, затем Save.
6. В Settings → Actions → General проверьте, что Actions разрешены, а workflow имеет право записывать изменения в репозиторий (если это понадобится).
7. Вкладка Actions позволяет вручную запустить `Weekly price refresh` через `Run workflow`.

## Расписание
Настроено на понедельник 07:17 по Калининграду (05:17 UTC; Калининград — UTC+2). GitHub предупреждает, что расписание иногда может стартовать с задержкой.
